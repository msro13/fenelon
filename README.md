# Archivo Fenelon

Galería familiar con 2.413 fotos escaneadas (1959–2000), ordenadas por año y álbum.

- `index.html` — la web (sin dependencias, abre directamente en el navegador).
- `data.json` — índice de álbumes y fotos.
- `a/` — las fotos agrupadas en hojas WebP (`t*` miniaturas, `d*` tamaño visor).

Para verla en línea: Settings → Pages → Deploy from a branch → `main` / `(root)`.
